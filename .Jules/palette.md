## 2025-02-18 - Semantic Labels for Forms
**Learning:** Using `<div>` instead of `<label for="id">` for form headings prevents screen readers from properly associating the label with the input field, and it also prevents users from clicking the label to focus the corresponding input.
**Action:** Always use `<label for="...">` instead of generic container tags for form headings/titles, linking them correctly to their respective inputs/textareas to improve accessibility and target sizes.
